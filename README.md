# Web-The-Farfalla

Tres propuestas de landing para **Sabores Farfalla** (Aldama 7, Centro, Chignahuapan, Pue.).

| Carpeta | Propuesta |
|---|---|
| `opcion-a/` | Mariposa: clara, ciruela y menta del logo |
| `opcion-b/` | Terraza de noche: oscura, guirnalda de focos |
| `opcion-c/` | Pinceladas: colores de la pintura de la mariposa |
| `index.html` | Selector para comparar las tres |

Son sitios estáticos (HTML, CSS y JS sin build).

## Despliegue en Netlify

- **Todo junto:** un sitio con *Base directory* vacío y *Publish directory* `.`. Las opciones quedan en `/opcion-a/`, `/opcion-b/` y `/opcion-c/`.
- **Un sitio por opción:** crea tres sitios desde este mismo repo y en cada uno pon *Base directory* y *Publish directory* en `opcion-a`, `opcion-b` u `opcion-c`. Deja vacío el *Build command*.
